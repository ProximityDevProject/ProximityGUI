# Proximity UI - план и предложения

> Своя GUI-библиотека для Roblox (Luau, исполнение через `loadstring`).
> Основа: **Compkiller** (структура окна, Link-система, конфиги, мобильный режим) + **Neverlose Reloaded** (премиальный вид, SubPage, ranged/text-слайдеры, keybind-лист, настройки-«шестерёнка» у тоггла) + **MugiGen2** (стили окна, popups, поиск-палитра, иконки SVG, HWID-конфиги, key system, анимации). Поверх - свои идеи.
> Дизайн: чёрная база, **белый акцент**, мотив «затмения» из `ProximityIcon.png` - чёрная сфера с белым светящимся ободом и бликом.

## 1. Архитектура

```
ProximityUI/
├─ src/
│  ├─ init.luau              -- точка входа, возвращает Library
│  ├─ Core/                  -- Signal, Maid(Janitor), Tween/Spring, Input, Scheduler, Util
│  ├─ Theme/                 -- токены, пресеты, биндинг свойств к токенам
│  ├─ Icons/                 -- реестр иконок (спрайт-атласы + rbxassetid + SVG)
│  ├─ Config/                -- Flags, сериализация, файлы, автосейв, импорт/экспорт
│  ├─ Window/                -- Window, Sidebar/Rail/Tiles, Topbar, Bubble, Resize, Drag
│  ├─ Containers/            -- Tab, SubTab, Section, Popup, Dialog, Option-панель
│  ├─ Elements/              -- Toggle, Button, Slider(+Range/+Text), Dropdown, Input, Keybind,
│  │                            ColorPicker, Label, Paragraph, Progress, Separator, List, ...
│  ├─ Widgets/               -- Notify, Watermark, KeybindList, Tooltip, CommandPalette, Loader
│  └─ Systems/               -- Search, Localization, Keybinds, Profiles, KeySystem (опц.)
├─ dist/Proximity.luau       -- один файл для loadstring (сборка darklua)
├─ examples/                 -- Full.luau, Minimal.luau, Mobile.luau
├─ tests/                    -- Lune-тесты чистой логики (конфиги, флаги, цвета, тема)
├─ assets/                   -- иконка (512/256/128/64), атласы иконок
├─ docs/                     -- API.md, Theming.md, Config.md, MIGRATION.md (с Compkiller/Neverlose/Mugi)
└─ .Tools/                   -- все инструменты (ничего на C:)
```

Принципы:
- **Модульный исходник, однофайловая сборка.** Пишем модулями, `darklua` бандлит в `dist/Proximity.luau`.
- **Один источник правды для цвета** - токены темы; каждый инстанс подписывается на токен, смена темы = один проход.
- **Maid на каждом объекте** - `Destroy()`/`Unload()` гарантированно чистят инстансы, коннекты, потоки.
- **Строгий Luau (`--!strict`) + экспорт типов**, чтобы автодополнение работало у пользователя.
- **Без побочных эффектов на игру** (никаких Part/DepthOfField в Workspace/Lighting по умолчанию).

### Черновик API

```lua
local Proximity = loadstring(game:HttpGet(URL))()

local Window = Proximity:Window({
    Title = "Proximity", Subtitle = "v1.0", Icon = "rbxassetid://...",
    Keybind = Enum.KeyCode.RightShift, Layout = "Sidebar", -- Sidebar | Rail | Tiles
    Size = UDim2.fromOffset(720, 480), Scale = "Auto",
    Config = { Folder = "Proximity", AutoSave = true },
})

Window:Category("Main")
local Combat = Window:Tab({ Name = "Combat", Icon = "crosshair" })
local Aim    = Combat:SubTab({ Name = "Aimbot" })              -- как SubPage у Neverlose
local Sec    = Aim:Section({ Name = "General", Side = "Left" })

local T = Sec:Toggle({ Name = "Enabled", Flag = "aim.enabled", Default = false, Risky = false,
                       Tooltip = "Включает наведение", Callback = print })
T:Keybind({ Default = Enum.KeyCode.E, Mode = "Hold" })        -- Link-цепочка
T:ColorPicker({ Default = Color3.new(1,1,1), Alpha = 0 })
T:Options(function(o)                                          -- шестерёнка-popup
    o:Slider({ Name = "Smooth", Min = 1, Max = 20, Default = 5 })
end)

Sec:Slider({ Name = "FOV", Min = 0, Max = 360, Default = 90, Suffix = "°", Step = 1 })
Sec:RangeSlider({ Name = "Distance", Min = 0, Max = 1000, Default = {10, 250} })
Sec:Dropdown({ Name = "Hit part", Values = {"Head","Torso"}, Multi = true, Search = true })

Window:SettingsTab()        -- тема, клавиша, масштаб, язык, виджеты, конфиги - одной строкой
Proximity:Notify({ Title = "Loaded", Content = "Proximity готов", Type = "success" })
```

Каждый элемент: `:Get() :Set(v, silent?) :SetVisible() :SetLocked(reason) :Destroy() .Changed (Signal)`.

## 4. Предложения

### 4.1 UX (25)

1. **Единая клавиша меню** + переназначение в настройках + запасной вариант «долгое нажатие на Bubble» для мобилки.
2. **Command Palette (Ctrl+K / «/»)** - нечёткий поиск по всем элементам, вкладкам, действиям; Enter переходит к элементу и подсвечивает его (идея Mugi, но с fuzzy-поиском и историей).
3. **Запоминание состояния**: последняя вкладка, позиция и размер окна, свёрнутые секции, прокрутка - восстанавливаются при перезапуске.
4. **ПКМ по любому элементу → контекстное меню**: «Сбросить по умолчанию», «Копировать значение», «Вставить», «Назначить клавишу», «Добавить в Избранное».
5. **Undo/Redo (Ctrl+Z / Ctrl+Y)** для изменений значений внутри сессии.
6. **Ввод точного значения слайдера**: двойной клик по числу превращает его в поле ввода; колесо мыши и стрелки ←/→ шагают, Shift - крупный шаг, Ctrl - мелкий.
7. **Предупреждение для Risky-функций**: первая активация показывает подтверждение с текстом риска, с галочкой «больше не спрашивать».
8. **Состояние «заблокировано» с причиной** (`SetLocked("Нужен Premium")`) - элемент виден, но тусклый, тултип объясняет почему.
9. **Зависимости элементов**: `DependsOn = "aim.enabled"` - зависимые элементы плавно скрываются/блокируются, когда родитель выключен.
10. **Поиск внутри Dropdown** автоматически при > 7 значениях, с клавиатурной навигацией ↑/↓/Enter/Esc.
11. **Режимы клавиш**: Toggle / Hold / Always / Release, переключение ПКМ по биндеру, как у Neverlose.
12. **KeybindList показывает только активные бинды** и режим каждого; перетаскивается и прилипает к краям экрана.
13. **Мобильный режим**: увеличенные хит-боксы (мин. 36 px), без hover-зависимой логики, кнопка-пузырь, свайп между вкладками.
14. **Авто-масштаб** по размеру экрана с ручным оверрайдом (50-200 %) и сохранением.
15. **Escape закрывает верхний слой**: dropdown → popup → dialog → окно, по порядку.
16. **Фокус-навигация с клавиатуры/геймпада**: Tab/Shift+Tab, стрелки, A/B на геймпаде.
17. **Тосты с действиями**: уведомление с кнопкой «Отменить» (например, после загрузки конфига).
18. **Избранное**: звёздочка у элемента выносит его во вкладку «Избранное» (живая ссылка, а не копия).
19. **Профили быстрого переключения**: «Legit / Rage / Off» - горячие клавиши для смены целого конфига.
20. **Безопасное закрытие**: Unload спрашивает подтверждение и выключает все тогглы с колбэками перед уничтожением.
21. **Подсказки первого запуска** (onboarding): 3-4 шага с подсветкой поиска, настроек, клавиши меню; отключаемо.
22. **«Что нового»** - диалог с изменениями при обновлении версии скрипта.
23. **Индикатор несохранённых изменений** у конфига (точка рядом с именем) и Ctrl+S для сохранения.
24. **Перетаскивание секций** между колонками с сохранением раскладки пользователя.
25. **Режим «Только просмотр»** окна (pin поверх игры с прозрачностью, клики проходят сквозь).

### 4.2 UI (25)

1. **Три макета навигации**: Sidebar (по умолчанию, как Compkiller/Neverlose), Rail (иконки), Tiles (домашний экран-плитки, как Mugi).
2. **Двухуровневая навигация**: Tab → SubTab (вкладки-таблетки сверху страницы, как SubPage у Neverlose).
3. **Колонки секций**: Left / Right / Full-width + авто-переход в одну колонку на узком окне.
4. **Секции со сворачиванием**, счётчиком включённых функций в заголовке и иконкой.
5. **Шестерёнка у тоггла** открывает мини-popup с доп. настройками (Neverlose `Settings` + Compkiller `Option`) - поверх, а не внутри секции.
6. **Хедер окна**: иконка-«затмение», название, подзаголовок, теги (FPS / Ping / Players / Executor), кнопки свернуть/закрыть.
7. **Профиль-карточка** внизу сайдбара: аватар, ник, статус лицензии/дней (как `TimeLeft` у Neverlose).
8. **Watermark** из модулей (`AddText` + динамические значения), перетаскиваемый, с выбором угла.
9. **Уведомления** 4 типов + прогресс-бар + стек до 5 штук + выбор угла экрана.
10. **Тултипы** с задержкой 400 мс, поддержкой RichText и горячих клавиш в тексте.
11. **ColorPicker-popup**: SV-квадрат, hue, alpha, HEX/RGB/HSV, 8 пресетов, «последние цвета», пипетка-копирование, сравнение «было/стало».
12. **RangeSlider** (две ручки) и **TextSlider** (дискретные подписи: Slow/Medium/Fast).
13. **Dropdown** single/multi с чипами выбранных значений и счётчиком «+3».
14. **Input** с режимами: текст, число (min/max), пароль, многострочный; кнопка очистки.
15. **Progress / Stat-плашки** для отображения значений (например, «Убийств: 12»).
16. **Таблица/список** (`List`) с выбором строки и кнопками на строке - для списков игроков, конфигов.
17. **Player-picker**: dropdown игроков сервера с аватарами, авто-обновление при входе/выходе.
18. **Dialog** модальный с затемнением и 1-3 кнопками (Danger-кнопка красная).
19. **Loader-экран** при старте: иконка, полоса загрузки, этапы («Иконки… Конфиги… Готово»).
20. **Пустые состояния**: «Конфигов пока нет - создайте первый» с кнопкой.
21. **Бейджи у вкладок/элементов**: NEW, BETA, RISKY, PREMIUM.
22. **Скроллбары тонкие** (2 px), утолщаются при наведении.
23. **Пузырь-кнопка** (перетаскиваемая) и **Topbar-кнопка** в верхней панели Roblox - для открытия на мобилке.
24. **Resize-уголок** окна с минимальным размером и «прилипанием» к сетке 8 px.
25. **Мини-режим окна**: свернуть в полоску-хедер, где видны только теги и кнопка разворота.

### 4.3 Новые функции (25)

1. **Command Palette** с действиями, а не только с элементами (`Window:Command("Reload", fn)`).
2. **Избранное** (вкладка с живыми ссылками на элементы).
3. **Профили и горячие клавиши профилей.**
4. **Undo/Redo-стек** значений.
5. **Импорт/экспорт конфига строкой** (Base64 + контрольная сумма) через буфер обмена.
6. **Диф конфигов**: перед загрузкой показать, какие значения изменятся.
7. **Версионирование схемы конфига** + миграции (переименованный флаг не теряется).
8. **Локализация**: `Proximity:SetLanguage("ru")`, таблицы строк, fallback на EN.
9. **Зависимости элементов** (`DependsOn`, `VisibleIf`, `LockedIf` с функцией).
10. **Пресеты значений** у слайдеров/дропдаунов (кнопки «Low / Mid / High»).
11. **Горячие клавиши на кнопки** (не только на тогглы).
12. **Keybind-комбинации** (Ctrl+Shift+X) и клавиши мыши (MB4/MB5).
13. **Встроенный FPS/Ping/Memory-монитор** как виджет и как теги окна.
14. **Graph-элемент**: маленький линейный график значения во времени (FPS, урон, скорость).
15. **Console/Log-панель**: вывод логов скрипта внутри GUI с фильтром уровней.
16. **Player-list элемент** с аватарами, поиском, действиями (Spectate/Teleport - задаёт разработчик скрипта).
17. **Notification-центр**: история уведомлений с колокольчиком в хедере.
18. **Темы-редактор** во вкладке настроек: живое изменение токенов + экспорт темы строкой.
19. **Key System** (по образцу Mugi): режим пароля и API-режим, с той же темой.
20. **Плагины/расширения**: `Proximity:RegisterElement("Name", ctor)` для своих элементов с поддержкой конфигов и темы.
21. **Синхронизация нескольких окон** одной библиотеки (общие флаги, одна система уведомлений).
22. **Скриншот-режим**: временно скрыть всё GUI одной клавишей (стримеры).
23. **Таймеры/расписание**: `Window:Schedule(every, fn)` с автоостановкой при Unload.
24. **Changelog-диалог** «Что нового» по версии.
25. **Ограничения элементов по уровню доступа** (`Tier = "Premium"`) - замок и тултип.

### 4.4 Улучшение существующих функций из исходников (22)

1. **Link-система Compkiller** → универсальная: к **любому** элементу можно прицепить Keybind, ColorPicker, Tooltip, Options, Badge, а не только к 4 типам.
2. **`IsFirstElement`/`IsLastElement` у Neverlose** → убрать ручную разметку: скругления первого/последнего элемента считаются автоматически.
3. **Тема Compkiller** (10+ цветов, `RefreshCurrentColor` после каждого) → токены с биндингом, смена темы одной функцией с кросс-фейдом 0.25 с.
4. **Blur Neverlose** (стеклянный Part + DepthOfField в Lighting) → по умолчанию без вмешательства в игру; опциональный blur только если включён пользователем и с полным откатом.
5. **Конфиги Mugi (HWID + аккаунт)** → оставить, но сделать опцией; добавить экспорт строкой и шифрование необязательным.
6. **Автосейв Mugi (debounce 1.5 с)** → плюс сохранение при Unload и защита от записи «полупостроенного» UI.
7. **Пакетная загрузка конфига Mugi (~6 значений/кадр)** → адаптивно по времени кадра (бюджет 2 мс).
8. **Поиск Mugi** → нечёткий поиск + поиск по тегам/описаниям + история.
9. **Стили Mugi (Sidebar/Rail/Pills/Tiles)** → оставить 3 лучших (Sidebar/Rail/Tiles), но с одним общим деревом вкладок, без дублирования инстансов.
10. **Popups Mugi** → привязка к элементу-источнику (появляется у шестерёнки, а не в центре), с автопозиционированием в пределах экрана.
11. **ColorPicker Neverlose (форматы цвета)** + **Mugi (Cancel/Done, пресеты)** → один пикер со всем этим + альфа + «последние».
12. **KeybindList Neverlose** → показ режима, сортировка, скрытие неактивных, перетаскивание с сохранением позиции.
13. **Watermark Compkiller** → модульные блоки с авто-обновлением (`AddDynamic(fn, interval)`).
14. **Loader Compkiller** → реальные этапы загрузки и прогресс, а не только таймер.
15. **Scale Compkiller (PC/Mobile)** → непрерывный авто-скейл от размера вьюпорта + ручной множитель.
16. **Dropdown Mugi (Deletable, ConfirmDelete)** → оставить и добавить reorder перетаскиванием.
17. **Иконки Mugi (имя/SVG/asset/URL)** → тот же резолвер, но приоритет на предзапечённые атласы (быстрее и стабильнее, чем рендер SVG).
18. **Notify Neverlose (позиционные аргументы)** → таблица опций + обратная совместимость со строкой.
19. **Resize Neverlose** → с сохранением размера и адаптацией колонок.
20. **UserSettings Compkiller** → `Window:SettingsTab()` одной строкой: тема, клавиша, язык, масштаб, виджеты, конфиги, Unload.
21. **Risky Compkiller** → плюс подтверждение и отдельный цвет/иконка в KeybindList и поиске.
22. **Topbar-кнопка Mugi** → тот же алгоритм, но с безопасным фоллбэком на Bubble, если CoreGui недоступен.

### 4.5 Доработка - слабые места исходников, которые мы закрываем (22)

1. Neverlose: ошибки в таблице клавиш (`RightParenthesis = " )"`, `Slash = "`"`, `RightBracked`, одинаковые `KeypadP`/`KeypadM`/`KeypadE` для разных клавиш) → своя таблица имён с тестом уникальности.
2. Neverlose: `GetConfig` и `GetFolder` объявлены дважды → один модуль конфигов, линтер `selene` ловит повторы.
3. Compkiller: опечатки в публичном API (`AlwayShowTab`, `Refersh`) → чистые имена + алиасы для совместимости.
4. Compkiller: элемент без `Flag` молча не сохраняется → предупреждение в debug-режиме и авто-флаг из пути `Tab.Section.Name` по желанию.
5. Mugi: смешанный позиционный/именованный формат аргументов → только именованные поля (+ строгие типы), позиционные только как легаси.
6. Mugi: минифицированный исходник - сложно дорабатывать → у нас читаемый исходник, минификация только в `dist/`.
7. Mugi: Topbar и Popups «не проверены на реальном клиенте» → чек-лист ручных тестов на 2-3 экзекуторах.
8. Neverlose: `getgenv().Library:Unload()` глобально → уникальный ключ `getgenv().__Proximity[id]`, не конфликтует с другими GUI.
9. Утечки коннектов при `Destroy` элементов → Maid на каждом объекте + тест «создать/уничтожить 1000 раз».
10. Колбэки, падающие с ошибкой, ломают UI → `SafeCall` с выводом стека в лог-панель и уведомлением (в debug).
11. Повторная загрузка скрипта плодит окна → автоматический Unload предыдущего экземпляра.
12. Двойной вызов колбэка при `Set` → флаг `silent` и сравнение со старым значением.
13. Отсутствие проверки границ (`Min > Max`, `Default` вне диапазона) → валидация с понятной ошибкой.
14. Dropdown с дублирующимися значениями → дедупликация/предупреждение.
15. Длинные названия обрезаются без подсказки → `TextTruncate` + тултип с полным текстом.
16. Наложение popups/dropdown за краем экрана → авто-flip вверх/влево.
17. Неработающий ввод при открытом чате / TextBox игры → игнор хоткеев при `GetFocusedTextBox()`.
18. Перекрытие ввода в игре при клике по GUI → правильный `Active`/`Modal`, без «простреливания» кликов в игру.
19. Нет обработки отсутствия `writefile`/`isfolder` → конфиги переходят в память с уведомлением.
20. Нет версии библиотеки в API → `Proximity.Version`, проверка обновления (опционально).
21. Нет документации типов → `export type` на все публичные объекты + `docs/API.md`.
22. Нет примеров «с нуля до конфига» → `examples/Minimal`, `Full`, `Mobile`, `Migration from Compkiller`.

### 4.6 Дизайн (25)

1. **Палитра-токены** (монохром):
   | Токен | Цвет | Назначение |
   |---|---|---|
   | `Bg` | `#050505` | фон окна |
   | `Surface` | `#0B0B0C` | сайдбар, секции |
   | `Surface2` | `#111113` | поля элементов |
   | `Elevated` | `#17171A` | popups, dropdown |
   | `Stroke` | `#1E1E22` | обводки |
   | `StrokeHi` | `#2C2C31` | обводка при наведении |
   | `Text` | `#F2F2F2` | основной текст |
   | `TextDim` | `#9B9BA1` | подписи |
   | `TextMute` | `#5E5E65` | неактивное |
   | `Accent` | `#FFFFFF` | заливки слайдеров, включённые тогглы, активная вкладка |
   | `AccentInk` | `#0A0A0A` | текст/иконка поверх белого |
   | `Risky` | `#E5484D` | единственный «цвет» по умолчанию |
2. **Акцент - чистый белый**: заливка слайдера, ручка, включённый тоггл (белая дорожка + чёрная точка), активная вкладка, фокус-кольцо.
3. **Мотив «затмения»**: тонкая белая дуга-подсветка (UIStroke + UIGradient), которая медленно обходит рамку окна - как светящийся обод на иконке. Скорость регулируется/отключается.
4. **Блик**: в правом верхнем углу окна мягкое радиальное свечение (как вспышка на иконке), очень низкая интенсивность.
5. **Фон окна**: почти чёрный градиент сверху вниз (`#070707 → #030303`) + опциональный шум/звёзды 2-3 % прозрачности.
6. **Белое свечение (glow)** у активных элементов - `ImageLabel` с 9-slice тенью, прозрачность 0.85-0.9, не заливка.
7. **Скругления**: окно 12, секции 8, элементы 6, чипы/тогглы полностью круглые.
8. **Обводки 1 px** везде вместо теней-плашек; при наведении `Stroke → StrokeHi`.
9. **Типографика**: Builder Sans / Montserrat (встроенные семейства Roblox); заголовки 15 Bold, элементы 13 Medium, подписи 11 Regular; цифры моноширинные (`RobotoMono`) в слайдерах и вотермарке.
10. **Сетка 4/8 px**: отступы секций 12, между элементами 6, высота строки элемента 32 (мобилка 40).
11. **Иконки**: один набор, outline, толщина 1.75 (как у Mugi), размер 16/18; в активном состоянии белые, в неактивном - `TextDim`.
12. **Тоггл**: Switch по умолчанию (дорожка `Surface2` → белая, точка белая → чёрная), альтернативы Checkbox и Chip.
13. **Слайдер**: тонкая дорожка 4 px, белая заливка, ручка-кружок появляется/растёт при наведении и перетаскивании, значение справа моноширинным.
14. **Кнопки**: Primary - белая заливка с чёрным текстом; Secondary - контур; Ghost - только текст; Danger - красный контур.
15. **Активная вкладка**: белая полоса-индикатор слева 2 px, которая пружинно «переезжает» между вкладками.
16. **Анимации**: длительность 0.15-0.25 с, `Quint Out`; пружины только для тогглов и индикатора; ничего не двигается без причины.
17. **Открытие окна**: fade + scale 0.96 → 1 + проявление обода «затмения»; закрытие - обратное.
18. **Ripple** белый с прозрачностью 0.9 при нажатии кнопок (выключаемо).
19. **Состояния элементов**: default / hover / press / focus / disabled / locked - у каждого задан стиль в токенах.
20. **Уведомления**: тёмная карточка, слева белая вертикальная полоса-прогресс, иконка типа в монохроме (успех/ошибка различаются формой иконки, а не цветом).
21. **Loader**: иконка-затмение в центре, вокруг вращается белая дуга, снизу тонкий прогресс-бар.
22. **Логотип**: иконку уменьшить до 512/256/128/64 и загрузить ассетом; для мелких размеров - упрощённая векторная версия (круг + дуга), иначе детали теряются.
23. **Пресеты тем** все остаются монохромными по базе: «Eclipse» (по умолчанию, белый), «Graphite» (серый акцент), «Moon» (холодный белый `#E8F0FF`), «Ash» (тёплый белый `#FFF4E6`), «OLED» (чистый `#000000`) + возможность своего акцента.
24. **Прозрачность окна** 0-40 % настраиваемая; контраст текста не ниже 7:1 к фону.
25. **Единый стиль для всех поверхностей** (окно, popup, dialog, уведомление, вотермарка, keybind-лист): одинаковые радиусы, обводки, шрифты - выглядит как одна система.

### 4.7 Производительность и стабильность (20)

1. Ленивая отрисовка вкладок: инстансы страницы создаются при первом открытии.
2. Пул инстансов для элементов списков, строк dropdown, уведомлений.
3. Один `RenderStepped`-диспетчер на всю библиотеку вместо коннекта на каждый элемент.
4. Анимации на `TweenService`, а пружины - в общем диспетчере, остановка при скрытом окне.
5. Обновление динамических тегов/вотермарки с интервалом, а не каждый кадр.
6. Смена темы - проход по реестру биндингов, без `GetDescendants()`.
7. Debounce записи файлов (конфиг, состояние окна) - не чаще раза в 1-1.5 с.
8. Бюджет загрузки конфига 2 мс/кадр.
9. Кэш иконок и картинок (в памяти + на диске), предзагрузка `ContentProvider:PreloadAsync` во время Loader.
10. Виртуализация длинных списков (игроки, логи, >100 строк).
11. Отключение скрытых страниц (`Visible=false`) вместо прозрачности.
12. CanvasGroup только там, где нужен fade группы, - они дорогие.
13. Режим «Performance»: выключает свечения, ripple, обод-анимацию, blur.
14. Тест на утечки: создание/уничтожение окна 100 раз, рост памяти ≈ 0.
15. Стресс-тест: 500 элементов, FPS не падает больше чем на 2 %.
16. `SafeCall` для всех пользовательских колбэков; ошибка одного не ломает остальные.
17. Отложенные колбэки (`task.defer`) при массовой загрузке, чтобы не блокировать кадр.
18. Ограничение стека уведомлений и истории (не растёт бесконечно).
19. Гарантированный `Unload`: отключение всех соединений, потоков, биндов, удаление GUI, сброс флагов.
20. Профайлер в debug-режиме: время построения окна, количество инстансов, коннектов.

### 4.8 Безопасность и совместимость с экзекуторами (20)

1. Обёртки `cloneref`, `gethui`, `protectgui` с безопасными фоллбэками.
2. Детект функций (`writefile`, `setclipboard`, `getcustomasset`, `gethwid`…) один раз при старте → таблица возможностей.
3. Корректная работа в Studio (без файловых API) - для разработки через Rojo.
4. Случайные/пустые имена инстансов GUI (как `"\0"` у Neverlose, `_RandomString` у Compkiller) - опционально.
5. Родитель GUI: `gethui()` → `CoreGui` → `PlayerGui` по доступности.
6. Не трогаем `Lighting`/`Workspace` без явной опции.
7. Конфиги без сырых HWID/UserId - только хэши (если включён режим привязки).
8. Санитизация имён конфигов (только `[%w%s%-%_%.]`).
9. Защита от path traversal (`../`) в именах файлов.
10. JSON-парсинг в `pcall`, битый конфиг не ломает запуск, а переименовывается в `.broken`.
11. Проверка типов значений при загрузке конфига (строка в слайдер не попадёт).
12. HttpGet иконок/картинок только по разрешённым доменам или из кэша.
13. Нет `loadstring` внутри библиотеки (кроме опциональной проверки обновлений, выключено по умолчанию).
14. Webhook-модуль (если будет) - выключен по умолчанию, URL никогда не логируется.
15. Key System: ключ не хранится открытым текстом, лимит попыток, таймаут.
16. Совместимость с мобильными экзекуторами (тач, отсутствие `mouse1click` и т.д.).
17. Совместимость с играми, которые сами используют TopbarPlus.
18. Не ломать `UserInputService.MouseBehavior`/курсор игры; восстановление при закрытии.
19. Флаг `Proximity.Debug` выводит диагностику только при включении.
20. Матрица протестированных экзекуторов в `docs/Compatibility.md`.

### 4.9 Developer Experience / API (20)

1. Единый стиль: `Window:Tab{}`, `Tab:Section{}`, `Section:Toggle{}` - короткие имена, только таблица опций.
2. Алиасы для миграции: `AddToggle`, `DrawTab`, `Page`, `SubPage` → одни и те же конструкторы.
3. `export type` для всех объектов → автодополнение в luau-lsp/VS Code.
4. Каждый элемент - `Changed: Signal`, `Get/Set`, `SetVisible`, `SetLocked`, `Destroy`.
5. `Proximity.Flags["aim.enabled"]` + `Proximity:OnFlag("aim.enabled", fn)`.
6. Вложенные флаги через точку и авто-группировка в JSON.
7. Цепочки: `Sec:Toggle{...}:Keybind{...}:ColorPicker{...}` (возвращают родителя или ссылку).
8. Понятные ошибки: «Slider 'FOV': Min (10) > Max (5)» с указанием вкладки/секции.
9. `Window:SettingsTab()` и `Window:ConfigTab()` - готовые вкладки одной строкой.
10. Хуки темы: `Proximity:SetTheme{ Accent = Color3 }`, `Proximity:OnThemeChanged(fn)`.
11. `Proximity:RegisterIcon(name, source)` и `RegisterElement(name, ctor)` для расширений.
12. Документация с примером на каждый метод и скриншотом.
13. `MIGRATION.md`: таблица соответствия Compkiller / Neverlose / Mugi → Proximity.
14. CHANGELOG и SemVer; `Proximity.Version`.
15. Сборка одной командой (`darklua process`), проверки одной командой (`stylua --check`, `selene`, `lune run tests`).
16. Rojo-проект с тестовым плейсом для живой разработки в Studio.
17. Шаблон скрипта (`examples/Template.luau`) с правильной структурой и Unload.
18. Debug-оверлей: подсветка границ секций/элементов, вывод флагов.
19. Стабильные ссылки `loadstring` на версию (`/v1.2.0/`) и `latest`.
20. Тесты чистой логики (конфиги, флаги, цвета, локализация) в Lune.
