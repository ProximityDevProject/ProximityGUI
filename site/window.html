Window

The window holds tabs, loads itself through the planet screen and remembers where you left it: position, size, tab and scroll of every page.

Options

local Window = Proximity:Window({
    Title = "My Hub", Subtitle = "v1.0",
    Logo = nil,                    -- nil: Proximity planet, false: vector planet, or an icon / asset / URL
    Keybind = "RightShift",        -- also "Ctrl+M", Enum.KeyCode.Insert
    Size = Vector2.new(740, 500),  -- mobile default is 600 x 380
    Scale = "Auto",                -- or 0.5 to 2
    Folder = "MyHub",              -- where configs and settings live
    Theme = "Eclipse", Accent = Color3.new(1, 1, 1),
    Font = "Builder Sans", Density = "Normal", ToggleStyle = "Switch",
    Navigation = "Sidebar",        -- or "Rail"
    Loading = { Style = "Planet", MinTime = 0.6 },   -- Planet, Orbit, Eclipse, Constellation, Terminal, Skeleton; false to skip
    KeySystem = false,             -- see below
    Animation = "Planet",          -- Rise, Zoom, Drop, Slide, Swing, Wipe, Unfold, Scan, Fade, None
    ToggleButton = nil,            -- bubble on phones only; "Bubble", "Topbar" or false
    Decoration = true,             -- faint planet in the corner
    Backdrop = "Stars",            -- "Grid", "Dots", "None"
    Background = nil,              -- { Image = "...", Dim = 0.6 } or { Gradient = { c1, c2 } }
    Changelog = { Version = "1.2", Notes = { "New aim", "Faster ESP" } },
    Version = "1.2", VersionUrl = "https://example.com/version.txt",
    Watermark = true, KeybindList = true, Profile = true, Status = "Premium",
    AutoReady = true, AutoLoad = true, CheckUpdates = true, UnlockMouse = true,
})

Loading screen

While your script declares tabs and elements, nothing is drawn yet: elements are stored instantly and built in small pieces each frame, so the game never freezes. Meanwhile the player sees the planet screen.

  • The planet is a 3D cloud of white, grey and black points lit from the top right, with a ring that passes behind and in front of it.
  • The bar under it shows real progress: built elements plus your steps, with an estimate of the time left.
  • When everything is ready, including the auto-load config, the planet bursts with a shock wave and the window grows out of it.
local step = Window:Task("Downloading assets", 20)    -- weight, default 10
step:Progress(0.5)
step:Done()

Window:Step("Warming up ESP", function(t)              -- runs in its own thread
    t:Progress(1)
end)

Window:OnReady(function() print("menu is ready") end)

Other loading screens: "Orbit" (orbits and a ring of ticks), "Eclipse" (a moon covers the sun as it loads), "Constellation" (stars joined line by line), "Terminal" (a boot console) and "Skeleton" (the menu shell inside the window). No loading at all: Loading = false. Players can also switch it in Settings.

Key system

One option turns it on or off. While the key is not accepted, nothing else of your script runs.

Proximity:Window({
    Title = "My Hub",
    KeySystem = {
        Keys = { "alpha-2026", "beta-2026" },              -- a fixed list, or
        Check = function(key) return key == "x" end,        -- your own check (can call HttpGet), or
        Url = "https://my.site/check?key=%s",              -- "true", "valid" or "ok" in the reply means valid
        GetKey = "https://my.site/getkey",                 -- copied by the "Get a key" button
        Discord = "https://discord.gg/invite",
        Attempts = 5, Cooldown = 30,                        -- lock for 30 s after 5 wrong keys
        Remember = true,                                    -- remember a good key on this device
        Note = "Keys reset every 24 hours",
    },
})

Proximity:Window({ KeySystem = true, ... })    -- turned on with the defaults
Proximity:Window({ KeySystem = false, ... })   -- off

Tabs and pages

Window:Category("Main")
local Visuals = Window:Tab({ Name = "Visuals", Icon = "esp", Badge = "NEW" })
local Players = Visuals:SubTab({ Name = "Players", Icon = "players" })     -- pill under the title
local Tuning = Visuals:SubPage({ Name = "Tuning", Hidden = true })         -- opened by a Navigate row
Players:Section({ Name = "ESP" }):Navigate({ Name = "Fine tuning", Page = Tuning })

Sections

local Aim = Combat:Section({
    Name = "Aim", Icon = "aimbot", Side = "Left",     -- "Right", "Full"
    Toggle = true, Flag = "aim", Enabled = true,      -- checkbox in the header turns the whole section on or off
    Collapsible = true, Risky = false,                -- risky sections get a thin red stripe
})
local Silent, Lock = Aim:Tabs({ "Silent", "Lock" }, { Flag = "aim.mode", Icons = { "silent", "lock" } })
Silent:Toggle({ Name = "Hit chance" })

The header shows how many toggles are on, for example 2/5.

Navigation styles

Window:SetNavigation("Rail")      -- icons only, names on hover, the window gets narrower
Window:SetNavigation("Sidebar")   -- full names

Open and close

On phones the window grows out of the floating planet button and folds back into it when hidden. On PC it opens with the menu key and fades in place, unless you set ToggleButton = "Bubble" or "Topbar".

Window:Open()  Window:Close()  Window:Toggle()  print(Window:IsOpen())

Mini mode

The button next to "hide" folds the window into a slim bar with the logo, FPS, ping and time. Click the bar to unfold.

Window:SetMini(true)

Background

Window:SetBackground({ Image = "rbxassetid://1234567", Dim = 0.6 })
Window:SetBackground({ Gradient = { Color3.fromRGB(18, 18, 22), Color3.new(0, 0, 0) }, Rotation = 90 })
Window:SetBackdrop("Stars")       -- "Grid", "Dots", "None"
Window:SetDecoration(false)       -- hide the planet in the corner

Keyboard and gamepad

Arrow keys move a white focus ring between rows of the open page, Left and Right change the value, Enter or Space activates, Tab and Shift + Tab switch tabs. On a gamepad: D-pad, A, B to go back, LB and RB for tabs. Moving the mouse hides the ring.

What's new and updates

Changelog shows a short list of changes once per version. Version plus VersionUrl quietly tells the player when your script has a newer version. Proximity checks its own updates the same way, turn it off with CheckUpdates = false.
