Loading screens

Seven ways to wait, all with real progress

Every screen shows what is being built and the time left. Players can switch it in Settings, or you pick one in code.

Menu animations

Eleven ways to open, all on springs

The window moves on a physical spring, so it lands with a natural settle. Press the key mid-way and it turns around smoothly. Click a style to watch it.

What you get

Everything a hub needs, already done

Planet intro

Points land on a turning 3D planet and fuse into it while your menu builds.

Key system

KeySystem = true and it is on. Keys, your own check or a URL.

Ctrl + K

Jump to any feature, tab or action from anywhere in the menu.

Configs that travel

Write less

Ten lines for a real menu

local Proximity = loadstring(game:HttpGet(URL))()
local Window = Proximity:Window({ Title = "My Hub", Animation = "Swing" })

local Aim = Window:Tab({ Name = "Combat", Icon = "aimbot" })
    :Section({ Name = "Aim", Toggle = true, Flag = "aim" })

Aim:Slider({ Name = "FOV", Min = 10, Max = 500, Default = 135 })
Aim:Toggle({ Name = "Triggerbot", Icon = "triggerbot" })
    :Keybind({ Default = "Ctrl+X", Mode = "Hold" })

Window:SettingsTab()
