The menu is built while a planet spins

The screen dims and a planet assembles itself from hundreds of white, grey and black points. Below it a progress bar shows real numbers: elements already built and your own loading steps, with the time left. When everything is ready the planet bursts and the window grows out of the explosion.

Window:Step("Loading item database", function(step)
    for i, chunk in chunks do
        load(chunk)
        step:Progress(i / #chunks)
    end
end)

Write less

Ten lines for a real menu

local Proximity = loadstring(game:HttpGet(URL))()
local Window = Proximity:Window({ Title = "My Hub" })

local Aim = Window:Tab({ Name = "Combat", Icon = "aimbot" })
    :Section({ Name = "Aim", Toggle = true, Flag = "aim" })

Aim:Slider({ Name = "FOV", Min = 10, Max = 500, Default = 135 })
Aim:Toggle({ Name = "Triggerbot", Icon = "triggerbot" })
    :Keybind({ Default = "Ctrl+X", Mode = "Hold" })

Window:SettingsTab()
