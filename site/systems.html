Systems

Everything around the elements: how settings are stored, how the menu looks, and what happens when something goes wrong.

Configs

Proximity:SaveConfig("legit", { Author = "me" })
Proximity:LoadConfig("legit")
Proximity:DeleteConfig("legit")          -- a notification lets you bring it back for 5 seconds
Proximity:RestoreBackup("legit")         -- the version before the last overwrite
Proximity:DiffConfig("legit")            -- what would change if you load it
Proximity:SetAutoLoad("legit")  Proximity:SetAutoSave("legit")
print(Proximity:ListConfigs())

Files are stored scrambled with a checksum, so a file edited by hand is noticed instead of loading broken values. Old plain JSON files still load. A backup of the previous version is kept on every save. Without file functions everything works in memory.

Share codes

local code = Proximity:ShareConfig("legit")   -- for example "aB3xY"
Proximity:ImportCode("aB3xY", "from-friend")

The config is uploaded as text to paste.rs and only the short id is shared. It needs the executor's request function. The long export string still works without the internet: Proximity:ExportConfig() and Proximity:ImportConfig(text).

Proximity:SetTheme("Moon")         -- Eclipse, OLED, Graphite, Moon, Ash, Steel
Proximity:SetAccent(Color3.fromRGB(255, 244, 230))
Proximity:AddTheme("Paper Moon", { Accent = "#E8F0FF", Stroke = "#20242C" })
Proximity.Theme.Paint(myFrame, { BackgroundColor3 = "Surface" })   -- your own frames follow the theme

Fonts

About 50 fonts: every family Roblox ships (read live from Enum.Font, so the list is always valid) plus open-licence fonts hosted with Proximity and loaded through getcustomasset.

print(Proximity:GetFonts())
Proximity:SetFont("Minecraft (Monocraft)")   -- also "VT323 (terminal)", "Silkscreen (pixel)", "Russo One", "Press Start 2P"...
Hosted fonts: Monocraft, VT323, Silkscreen, Russo One, Space Mono, Audiowide, Rajdhani, Share Tech Mono, Righteous. All under the SIL Open Font License.

Density and styles

Proximity:SetDensity("Compact")      -- Compact, Normal, Comfortable, Touch
Proximity:SetToggleStyle("Orbit")    -- Switch, Compact, Checkbox, Chip, Radio, Square, Pill, Dot, Orbit

Touch makes rows taller for fingers without making the window fullscreen.

Notifications

Proximity:Notify({ Title = "Saved", Content = "legit", Type = "success", Duration = 4,
    Actions = { { Text = "Undo", Callback = function() Proximity:Undo() end } } })
Proximity:SetNotifyPosition("TopRight")

Hovering pauses the timer. Everything lands in the bell in the header, with a counter of unread ones.

Errors and debug

Proximity:OnError(function(message, trace)
    -- send it to your own log
end)
Proximity:SetDebug(true)    -- overlay: elements, flags, instances, memory, build time per tab

Wrong options produce a readable message instead of silent breakage, for example Slider "FOV": Min (500) is bigger than Max (10), swapped them. With debug on, every tooltip also shows the element type and flag.

Saving FPS

If FPS stays under 30 for six seconds, Proximity turns off the stars and the corner planet and tells the player once. Turn it off in Settings or call Proximity:SetEconomy(true) yourself.

Anonymous mode

Proximity:SetAnonymous(true, { Name = "Player" })   -- hides name, avatar, IDs and position everywhere
