Widgets

Small panels that live outside the window. All of them can be dragged, snap to corners and edges of the screen and remember where you put them. The settings tab has switches for each.

Docking

Proximity:Dock(myFrame, "MyWidget", { AnchorPoint = Vector2.new(1, 0), Position = UDim2.new(1, -12, 0, 12) })

Watermark

local wm = Proximity:Watermark({ Items = { "FPS", "Graph", "Ping", "Time" } })
wm:SetItems({ "FPS", "Ping", "Session", "Memory", "Speed" })
wm:AddItem({ Text = function() return "kills " .. kills end, Interval = 1 })

Available items: FPS, Graph (a live FPS line), Ping, Time, Date, Game, Player, Players, Executor, Session, Memory, Position, Speed, Uptime, Version, Server. Players pick them with checkboxes in Settings.

Keybind list

local binds = Proximity:KeybindList({ ShowInactive = true })

Active binds are bright, inactive ones grey. Sorting: active first, by name or by key.

Player panel

Proximity:PlayerPanel()

A slowly turning 3D copy of your character with health, speed, state and position.

FPS and ping graph

Proximity:PerfGraph()

Stopwatch

Proximity:Stopwatch()

A stopwatch with start, pause and reset, plus the time you spent in this session.

Your own HUD

local hud = Proximity:Widget({ Title = "Farm", Icon = "farm", Width = 220 })
hud:Toggle({ Name = "Auto farm", Flag = "farm" })
hud:Slider({ Name = "Radius", Min = 10, Max = 200, Default = 60 })
hud:SetVisible(true)

Any element works inside, with configs and keyboard focus.

Topbar button

On phones a round, draggable planet button floats on screen: tap it to open or close the window, which folds into it when hidden. On PC there is no button by default - the menu key opens the window. Force one with ToggleButton = "Bubble" or "Topbar" (next to the Roblox menu), or turn it off everywhere with false.
