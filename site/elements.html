Elements

Every element is created from a section, works before it is drawn, and saves itself into configs when it has a Flag. Constructors also exist as AddToggle, CreateToggle and so on.

Shared API

Toggle

local fly = Section:Toggle({ Name = "Fly", Icon = "fly", Flag = "fly", Risky = false, Callback = function(on) end })
fly:Keybind({ Default = "F", Mode = "Toggle" })
fly:Options(function(o)
    o:Slider({ Name = "Speed", Min = 1, Max = 200, Default = 50, Flag = "fly.speed" })
end)

Styles: Switch, Compact (a circle that fills), Checkbox, Chip (ON / OFF), Radio, Square, Pill, Dot, Orbit. Set one for the whole menu with Proximity:SetToggleStyle("Orbit") or per toggle with Style. Risky toggles ask before turning on.

Slider

    Presets = { Small = 60, Big = 300 } })

Section:TextSlider({ Name = "Smooth", Labels = { "Instant", "Fast", "Slow" }, Default = "Fast" })

Double click the number to type an exact value. Arrow keys nudge it while hovered, Shift moves by 10.

Dropdown

Section:Dropdown({ Name = "Part", Values = { "Head", "Torso" }, Default = "Head" })
Section:MultiDropdown({ Name = "Parts", Values = { "Head", "Torso", "Arms" }, Default = { "Head" }, Max = 2 })
Section:PlayerDropdown({ Name = "Target", Multi = false })

Multi selections show as chips with a cross. Search appears by itself above 7 values. Deletable, Icons, Prefixes, Display are optional.

Input

Keybind

Section:Keybind({ Name = "Panic", Default = "Ctrl+Shift+P", Mode = "Press", OnPress = function() end })
Section:Keybind({ Name = "Zoom", Default = "LeftShift", Mode = "Hold" })   -- a modifier on its own works too

Click the chip and press keys: holding Ctrl, Shift or Alt makes a combo. Right click the chip to change the mode: Toggle, Hold, Always, Release, Press. Backspace clears, Esc cancels. Roblox does not pass side mouse buttons to scripts, so MB4 and MB5 cannot be bound.

Table

Section:Table({
    Columns = { { Key = "name", Name = "Map", Width = 0.5 }, { Key = "players", Name = "Players", Width = 0.25 } },
    Rows = rows, SortBy = "players", Descending = true,
    Filters = {
        { Key = "players", Name = "Players", Type = "Range" },                  -- from and to
        { Key = "name", Name = "Map", Type = "Select", Values = { "Border" } },
        { Key = "full", Name = "Hide full", Type = "Switch", Test = function(row) return row.players < 30 end },
    },
    Actions = { { Icon = "log-in", Tooltip = "Join", Callback = function(row) end } },
})

Only visible rows exist, so thousands of rows stay smooth. A badge on the filter button shows how many filters are active.

Your own element

local Rating = Proximity.Base.extend("Rating")
function Rating.new(section, options)
    local self = Proximity.Base.new(Rating, section, options)
    self.Default = options.Default or 3
    self.Value = self.Default
    return self:_register()
end
function Rating:_build(parent) self:_row(parent) end
Proximity:RegisterElement("Rating", Rating)
Section:Rating({ Name = "Quality", Flag = "quality" })

Your element gets flags, configs, search, tooltips, locking, keyboard focus and undo for free.
