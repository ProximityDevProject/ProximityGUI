Guide

Your first Proximity menu

Five minutes from an empty file to a menu with tabs, a config system and settings. Everything below works as is, copy the blocks one after another.

Load it

One line. It always points to the latest build in the repository.

Tip. Put local Proximity = in front of the line, the library returns itself.

Three addresses serve the same file, use whichever you like:

AddressWhen to use it
https://proximitydevproject.github.io/ProximityGUI/Proximity.luathis site, always the latest version
https://proximitydevproject.github.io/ProximityGUI/v/1.2.7.luaa fixed version, updates never change your script
https://raw.githubusercontent.com/ProximityDevProject/ProximityGUI/main/dist/Proximity.luaustraight from the repository

First window

local Proximity = loadstring(game:HttpGet("https://raw.githubusercontent.com/ProximityDevProject/ProximityGUI/main/dist/Proximity.luau"))()

local Window = Proximity:Window({
    Title = "My Hub",
    Subtitle = "v1.0",
    Keybind = Enum.KeyCode.RightShift,   -- shows and hides the menu
})

The screen dims, the planet assembles, the menu is built behind it and then the window grows out of the burst. A planet button appears next to the Roblox menu: click it or press the menu key to hide and show the window.

Tabs and sections

Window:Category("Main")
local Combat = Window:Tab({ Name = "Combat", Icon = "aimbot", Description = "Aim and weapons" })

local Aim = Combat:Section({ Name = "Aim", Icon = "target" })               -- left column
local Weapon = Combat:Section({ Name = "Weapon", Side = "Right" })          -- right column
local Info = Combat:Section({ Name = "Info", Side = "Full" })               -- full width

Icons accept readable names like aimbot, esp, fly, farm or any of the 818 Lucide icons. See icons.

Elements

Aim:Toggle({ Name = "Enabled", Flag = "aim.on", Callback = function(on)
    print("aim", on)
end })

Aim:Slider({ Name = "FOV", Min = 10, Max = 500, Default = 135, Suffix = " px", Flag = "aim.fov" })
Aim:Dropdown({ Name = "Part", Values = { "Head", "Torso" }, Default = "Head", Flag = "aim.part" })
Aim:Keybind({ Name = "Aim key", Default = "MB2", Mode = "Hold", Flag = "aim.key" })
Weapon:ColorPicker({ Name = "Tracer color", Default = Color3.new(1, 1, 1), Flag = "weapon.tracer" })
Weapon:Button({ Name = "Reload", Icon = "rotate-ccw", Callback = function() end })

Every element has the same core: :Get(), :Set(value), .Changed, :Lock(reason), :DependsOn(flag), :Destroy(). All of them are listed on the elements page.

Flags and configs

Give an element a Flag and it is saved in configs automatically. Read live values from Proximity.Flags.

print(Proximity.Flags["aim.fov"])          -- 135
Proximity:OnFlag("aim.on", function(on) end)
Proximity:SaveConfig("legit")
Proximity:LoadConfig("legit")

Settings in one line

Window:Home()          -- dashboard: profile, live FPS and ping, server
Window:Favorites()     -- starred features
Window:SettingsTab()   -- theme, font, density, widgets, configs, unload

Your loading steps

If your script downloads something at start, show it as a step. The progress bar under the planet counts it, and the time left is calculated from the real speed.

Window:Step("Fetching player data", function(step)
    for i = 1, 10 do
        step:Progress(i / 10)
        task.wait(0.1)
    end
end)
